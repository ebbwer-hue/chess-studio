# Шахматный движок

Скачайте подходящую Windows x64 сборку [Stockfish](https://stockfishchess.org/download/) и распакуйте её в эту папку. Сервер рекурсивно ищет файл с именем stockfish*.exe. Сохраните файлы лицензии и авторства из архива.

Движок Stockfish распространяется отдельно по GPLv3: [исходный код](https://github.com/official-stockfish/Stockfish).
