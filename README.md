# Chess Studio

**Автор проекта: Кушалиев Амир** · [Telegram: @foidslayer1038](https://t.me/foidslayer1038)

Локальное шахматное приложение с интерфейсом в браузере: игра, анализ позиции и настройка силы Stockfish.

**Стек:** Node.js · JavaScript · HTML · CSS · Stockfish · chess.js.

## Возможности

- Интерактивная доска и проверка легальных ходов.
- Игра белыми и чёрными, рокировка и превращение пешек.
- Анализ движком Stockfish и настройка его силы.

## Запуск из исходников

1. Установите Node.js 22 или новее.
2. Скачайте Windows x64 сборку Stockfish и распакуйте её в `engine/`, следуя инструкции в этой папке.
3. Откройте `START.bat` или выполните `node server.cjs`.
4. Откройте адрес, который напечатает сервер. Для остановки нажмите Ctrl+C.

Репозиторий содержит исходники. Node.js и бинарный движок устанавливаются отдельно. Инструкция к исходной переносимой сборке сохранена в `README.txt`; для этого репозитория используйте шаги выше. Поддерживается Windows x64.
